A 4,096-byte chess engine for the [tiny-chess-01](https://make.fun/bounty/tiny-chess-01) bounty. It searches to a fixed 150,000-node cap (never a clock) with PVS, a transposition table, ply-capped quiescence, null move, bishop-pair evaluation, and check extensions.

## Run it

```sh
node cli/makefun.mjs grade-local --kit . --bot . --driver docker
```
